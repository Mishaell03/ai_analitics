## 1. Создаём вычисляемый столбец

В таблице магазина уже есть `quantity` — количество единиц товара — и `unit_price` — цена одной единицы в рублях. Но столбца с выручкой позиции пока нет.

**Вычисляемый столбец** содержит результат формулы, применённой к значениям других столбцов. Например:

`line_revenue = quantity × unit_price`

Проверим это на **двух завершённых позициях исходного набора**: 2001 (Mug) и 2002 (Notebook).

```python
import pandas as pd
from io import StringIO

csv_text = """line_item_id,quantity,unit_price,status
2001,2,450,completed
2002,3,180,completed
"""

df = pd.read_csv(StringIO(csv_text))
df["line_revenue"] = df["quantity"] * df["unit_price"]

print(df[["line_item_id", "line_revenue"]])
```

Результат:

```text
   line_item_id  line_revenue
0          2001           900
1          2002           540
```

Что делает строка `df["line_revenue"] = df["quantity"] * df["unit_price"]`?

1. Берёт значения `quantity` и `unit_price` в **одних и тех же строках**.
2. Умножает их: `2 × 450 = 900`, `3 × 180 = 540`.
3. Записывает результаты в новый столбец `line_revenue`.

pandas выполняет вычисление сразу для всего столбца. **Писать отдельный цикл `for` не требуется.** При этом исходные `quantity` и `unit_price` остаются на месте.

Не путайте показатели: `unit_price` — цена **одной единицы**, а `line_revenue` — выручка **всей товарной позиции**. Если количество больше единицы, эти числа обычно различаются.

## 2. Сначала выбираем нужные записи

По правилам «Северного света» в **учебную выручку** включаются только позиции со статусом `completed`. Отменённые позиции (`cancelled`) не учитываются.

Следующий пример использует **четыре позиции исходной таблицы**: 2001, 2002, 2006 и 2007. Позиция 2006 отменена.

```python
import pandas as pd
from io import StringIO

csv_text = """line_item_id,category,quantity,unit_price,status
2001,Home,2,450,completed
2002,Stationery,3,180,completed
2006,Accessories,1,900,cancelled
2007,Home,1,450,completed
"""

df = pd.read_csv(StringIO(csv_text))

completed_df = df[df["status"] == "completed"].copy()
completed_df["line_revenue"] = (
    completed_df["quantity"] * completed_df["unit_price"]
)

print(completed_df[["line_item_id", "line_revenue"]])
print("Завершённых позиций:", len(completed_df))
```

Результат:

```text
   line_item_id  line_revenue
0          2001           900
1          2002           540
3          2007           450
Завершённых позиций: 3
```

Разберём последовательность:

1. `df["status"] == "completed"` проверяет статус каждой строки.
2. `df[...]` выбирает только завершённые позиции.
3. `.copy()` создаёт **отдельный DataFrame**, в котором удобно выполнять дальнейшие расчёты, не изменяя исходную таблицу.
4. В новом DataFrame создаётся столбец `line_revenue`.

Исходная позиция 2006 не попала в итоговый набор. Если бы мы просто умножили количество на цену **во всех строках** и сложили результаты, стоимость отменённой позиции исказила бы выручку.

**Важно:** успешное вычисление не доказывает качество данных. Если `quantity` отсутствует, содержит текст или отрицательное число, либо цена нарушает правила, значения сначала нужно исследовать. Подробный аудит качества данных будет в следующем уроке.

## 3. Суммируем значения с помощью `sum()`

Выручка отдельной позиции — это одно значение `line_revenue`. Чтобы получить общую учебную выручку всех выбранных позиций, нужно сложить значения этого столбца.

В pandas используется метод `.sum()`:

```python
import pandas as pd
from io import StringIO

csv_text = """line_item_id,category,quantity,unit_price,status
2001,Home,2,450,completed
2002,Stationery,3,180,completed
2006,Accessories,1,900,cancelled
2007,Home,1,450,completed
"""

df = pd.read_csv(StringIO(csv_text))
completed_df = df[df["status"] == "completed"].copy()
completed_df["line_revenue"] = (
    completed_df["quantity"] * completed_df["unit_price"]
)

total_revenue = completed_df["line_revenue"].sum()

print("Учебная выручка:", total_revenue)
print("Завершённых позиций:", len(completed_df))
```

Результат:

```text
Учебная выручка: 1890
Завершённых позиций: 3
```

Проверим вручную: `900 + 540 + 450 = 1890` рублей.

Это **выручка только рассматриваемого фрагмента из четырёх исходных записей**, а не всего магазина.

Не смешивайте разные показатели:

| Показатель | Что измеряет |
|---|---|
| `line_revenue` | Выручку одной товарной позиции |
| `completed_df["line_revenue"].sum()` | Общую выручку выбранных завершённых позиций |
| `len(completed_df)` | Количество завершённых **строк** |
| `completed_df["order_id"].nunique()` | Число разных завершённых заказов, **если** в таблице есть `order_id` |

Количество строк нельзя автоматически считать количеством заказов: один `order_id` может встречаться в нескольких товарных позициях.

## 4. Группировка: из отдельных строк в итог по категориям

Руководителю часто недостаточно общей суммы. Например, он хочет узнать:

> Какая категория товаров принесла больше учебной выручки?

В нашем небольшом фрагменте категория `Home` представлена двумя завершёнными позициями. Чтобы получить **одну сумму для всей категории**, нужно объединить их значения.

**Агрегация** — это получение обобщённого показателя из нескольких записей. Сумма выручки по категории — пример агрегации.

Для неё используется `groupby()`:

```python
import pandas as pd
from io import StringIO

csv_text = """line_item_id,category,quantity,unit_price,status
2001,Home,2,450,completed
2002,Stationery,3,180,completed
2006,Accessories,1,900,cancelled
2007,Home,1,450,completed
"""

df = pd.read_csv(StringIO(csv_text))
completed_df = df[df["status"] == "completed"].copy()
completed_df["line_revenue"] = (
    completed_df["quantity"] * completed_df["unit_price"]
)

category_revenue = (
    completed_df.groupby("category")["line_revenue"].sum()
)
category_revenue = category_revenue.sort_values(ascending=False)

print(category_revenue)
```

Результат:

```text
category
Home          1350
Stationery     540
Name: line_revenue, dtype: int64
```

Разберём команду по частям:

- `completed_df` — только завершённые позиции.
- `.groupby("category")` — объединяет строки с одинаковым значением `category` в группы.
- `["line_revenue"]` — указывает, **какой показатель** нужно объединять.
- `.sum()` — складывает выручку внутри каждой группы.
- `.sort_values(ascending=False)` — показывает категории от большей выручки к меньшей.

Здесь `category` — **признак группировки**, `line_revenue` — **числовой показатель**, `sum()` — **способ агрегации**.

Полученный результат — это краткая сводка по категориям, а не исходные товарные позиции. Каждая категория встречается в сводке один раз.

Сортировка не меняет суммы: она только переставляет строки результата. Категория `Accessories` отсутствует, потому что единственная её позиция в **этом фрагменте** отменена. Это не означает, что во всём исходном наборе нет завершённых продаж категории `Accessories`.

### 4.1. Проверяем, сошлись ли суммы

В том же небольшом примере мы получили:

| Категория | Учебная выручка, руб. |
|---|---:|
| Home | 1350 |
| Stationery | 540 |
| **Всего** | **1890** |

`1350 + 540 = 1890` — такой же результат, как сумма по отдельным завершённым позициям.

Проверять это можно непосредственно в Python:

```python
import pandas as pd
from io import StringIO

csv_text = """line_item_id,category,quantity,unit_price,status
2001,Home,2,450,completed
2002,Stationery,3,180,completed
2006,Accessories,1,900,cancelled
2007,Home,1,450,completed
"""

df = pd.read_csv(StringIO(csv_text))
completed_df = df[df["status"] == "completed"].copy()
completed_df["line_revenue"] = (
    completed_df["quantity"] * completed_df["unit_price"]
)
category_revenue = completed_df.groupby("category")["line_revenue"].sum()

print("Итого по позициям:", completed_df["line_revenue"].sum())
print("Итого по категориям:", category_revenue.sum())
```

Результат:

```text
Итого по позициям: 1890
Итого по категориям: 1890
```

**Почему эти суммы должны совпадать?** Каждая завершённая строка в нашем примере имеет ровно одну заполненную категорию, поэтому её выручка входит в одну группу и учитывается один раз.

Если суммы различаются, нужно проверить фильтрацию, пропущенные категории и то, из каких строк вычислены показатели. При отсутствии категории pandas по умолчанию может не включить такую строку в обычный `groupby()`.

### Разбор решения

```python
import pandas as pd
from io import StringIO

csv_text = """line_item_id,category,quantity,unit_price,status
2003,Home,1,2400,completed
2004,Accessories,2,900,completed
2005,Stationery,5,180,completed
2006,Accessories,1,900,cancelled
2009,Accessories,1,900,completed
"""

df = pd.read_csv(StringIO(csv_text))

completed_df = df[df["status"] == "completed"].copy()
completed_df["line_revenue"] = (
    completed_df["quantity"] * completed_df["unit_price"]
)

category_revenue = (
    completed_df.groupby("category")["line_revenue"].sum()
    .sort_values(ascending=False)
)

print("Завершённых позиций:", len(completed_df))
print("Всего выручка:", completed_df["line_revenue"].sum())
print("По категориям:")
print(category_revenue)
print("Проверка:", category_revenue.sum())
```

Основные результаты:

```text
Завершённых позиций: 4
Всего выручка: 6000
По категориям:
category
Accessories    2700
Home           2400
Stationery      900
Name: line_revenue, dtype: int64
Проверка: 6000
```

**Как получились суммы:**

- `Accessories`: `2 × 900 + 1 × 900 = 2700` руб.
- `Home`: `1 × 2400 = 2400` руб.
- `Stationery`: `5 × 180 = 900` руб.
- Отменённая позиция 2006 в расчёт не включена.

**Аналитический вывод:** в выбранном фрагменте лидирует `Accessories` с выручкой 2700 рублей. Самая высокая цена единицы — у товара категории `Home`, но её выручка в этом фрагменте ниже. Цена отдельного товара и суммарная выручка категории — разные показатели.

## 6. Ошибки, которые могут испортить расчёт

**1. Включили отменённые позиции.** Программа выполнится, но завысит выручку. Рассмотрим реальный фрагмент из двух позиций:

```python
import pandas as pd
from io import StringIO

csv_text = """line_item_id,quantity,unit_price,status
2004,2,900,completed
2006,1,900,cancelled
"""

df = pd.read_csv(StringIO(csv_text))
df["line_revenue"] = df["quantity"] * df["unit_price"]

print("Сумма без фильтра:", df["line_revenue"].sum())
```

Результат:

```text
Сумма без фильтра: 2700
```

Код **работает**, но корректная учебная выручка этих двух позиций — **1800 рублей**: ещё 900 рублей относятся к отменённой позиции.

**2. Сложили цены вместо выручки.** Выражение `df["unit_price"].sum()` складывает цены за одну единицу, не учитывая `quantity`. Для выручки каждой позиции нужна формула `quantity * unit_price`.

**3. Перепутали строки и заказы.** `len(completed_df)` считает завершённые товарные позиции. Если в данных есть `order_id`, количество различных завершённых заказов определяется через `completed_df["order_id"].nunique()`.

**4. Сгруппировали данные без нужного фильтра.** Если выручка рассчитана и просуммирована по всем статусам, в категории могут попасть отменённые позиции. Фильтрация должна соответствовать бизнес-вопросу.

**5. Ошиблись в названии столбца.** Например, `df["unitprice"]` не найдёт существующий столбец `unit_price` и вызовет `KeyError`. Проверьте точное имя через `df.columns`.

**6. Приняли сводку за исходную таблицу.** Результат `groupby("category")["line_revenue"].sum()` содержит суммы по категориям, а не отдельные товарные позиции.

**7. Назвали выручку прибылью.** В нашем учебном расчёте не учитываются себестоимость, скидки, возвраты, налоги и доставка. Выручка не равна прибыли.

**8. Не проверили данные до вычисления.** Пропуск количества, неверный тип цены или неожиданное значение статуса требуют проверки. Сам по себе `.sum()` не подтверждает корректность исходных записей.
