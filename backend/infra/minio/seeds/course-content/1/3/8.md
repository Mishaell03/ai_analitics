## 1. Что такое фильтрация

### 1.1. Зачем выбирать строки?

В исходной таблице «Северного света» находятся десять товарных позиций:

- Девять позиций имеют статус `completed`.
- Одна позиция имеет статус `cancelled`.

Если нас интересуют только завершённые продажи, отменённую позицию нужно исключить из рассматриваемого набора.

**Фильтрация** — это выбор строк таблицы, которые удовлетворяют определённому условию.

Например:

- Только завершённые позиции.
- Только товары стоимостью от 900 рублей за единицу.
- Только позиции, в которых количество не меньше двух.
- Только записи, отвечающие нескольким условиям одновременно.

Фильтрация не обязательно удаляет данные из исходной таблицы. Мы можем создать **новый DataFrame**, содержащий только подходящие строки.

### 1.2. Первая логическая маска

Рассмотрим четыре позиции из исходной таблицы магазина.

```python
import pandas as pd
from io import StringIO

csv_text = """line_item_id,order_id,product,quantity,unit_price,status
2004,5003,Bottle,2,900,completed
2005,5004,Notebook,5,180,completed
2006,5005,Bottle,1,900,cancelled
2007,5006,Mug,1,450,completed
"""

df = pd.read_csv(StringIO(csv_text))

print(df["status"] == "completed")
```

Результат:

```text
0     True
1     True
2    False
3     True
Name: status, dtype: bool
```

Что здесь произошло?

Выражение `df["status"] == "completed"` сравнивает значение статуса **в каждой строке** с текстом `"completed"`.

Для каждой строки получается:

| Индекс строки | line_item_id | status | Результат |
|---|---|---|---|
| 0 | 2004 | completed | `True` |
| 1 | 2005 | completed | `True` |
| 2 | 2006 | cancelled | `False` |
| 3 | 2007 | completed | `True` |

Получившаяся последовательность значений `True` и `False` называется **логической маской**.

Маска показывает, какие строки удовлетворяют условию.

Пока мы только проверили статусы. Сам DataFrame ещё не отфильтрован.

### 1.3. Выбираем строки с помощью маски

Теперь используем условие для получения подходящих записей.

```python
import pandas as pd
from io import StringIO

csv_text = """line_item_id,order_id,product,quantity,unit_price,status
2004,5003,Bottle,2,900,completed
2005,5004,Notebook,5,180,completed
2006,5005,Bottle,1,900,cancelled
2007,5006,Mug,1,450,completed
"""

df = pd.read_csv(StringIO(csv_text))

completed_df = df[df["status"] == "completed"]

print(completed_df)
```

В результате будут выбраны позиции:

- 2004 — Bottle.
- 2005 — Notebook.
- 2007 — Mug.

Позиция 2006 не попадёт в результат, поскольку её статус — `cancelled`.

Разберём выражение:

```python
completed_df = df[df["status"] == "completed"]
```

Внутренняя часть `df["status"] == "completed"` создаёт логическую маску.

Внешняя часть `df[...]` использует эту маску для выбора строк.

Полученные строки сохраняются в новой переменной `completed_df`.

**Важно:** такой способ фильтрации не изменяет исходный `df`. Если снова вывести `df`, в нём по-прежнему будут все четыре строки.

### 1.4. Почему индексы после фильтрации могут идти не подряд?

В исходной таблице индексы строк были:

`0, 1, 2, 3`

После фильтрации остались:

`0, 1, 3`

Индекс `2` пропущен, поскольку соответствующая запись не прошла условие.

Это нормально: pandas сохраняет исходные индексы выбранных строк.

**Не путайте индекс DataFrame и `line_item_id`:**

- Индекс — служебная метка строки в pandas.
- `line_item_id` — идентификатор товарной позиции в нашей учебной модели.

Это разные значения.

## 2. Фильтрация по числовым условиям

В прошлом уроке вы использовали операторы сравнения в Python:

`>`, `<`, `>=`, `<=`, `==`, `!=`

В pandas они тоже применяются к значениям столбцов.

Например, руководитель хочет увидеть позиции, содержащие **не меньше двух единиц товара**.

```python
import pandas as pd
from io import StringIO

csv_text = """line_item_id,order_id,product,quantity,unit_price,status
2004,5003,Bottle,2,900,completed
2005,5004,Notebook,5,180,completed
2006,5005,Bottle,1,900,cancelled
2007,5006,Mug,1,450,completed
"""

df = pd.read_csv(StringIO(csv_text))

selected_df = df[df["quantity"] >= 2]

print(selected_df[["line_item_id", "quantity"]])
print("Найдено позиций:", len(selected_df))
```

Результат:

```text
   line_item_id  quantity
0          2004         2
1          2005         5
Найдено позиций: 2
```

Здесь:

- `>= 2` означает «больше или равно двум».
- Позиция с количеством ровно 2 включается.
- Позиция с количеством 1 исключается.

Если заменить `>= 2` на `> 2`, позиция с количеством ровно 2 уже не подойдёт.

**`len(selected_df)`** возвращает количество выбранных строк.

Также число строк можно получить через `selected_df.shape[0]`: первое значение `shape` обозначает количество строк, второе — количество столбцов.

Важное наблюдение: фильтр по количеству **сам по себе не учитывает статус**. Если отменённая позиция содержит две единицы товара, она тоже попадёт в результат такого фильтра.

Поэтому условие нужно выбирать в соответствии с аналитическим вопросом.

## 3. Объединяем несколько условий

### 3.1. Оператор `&` — логическое «И»

Предположим, нужно найти позиции, которые одновременно:

1. Имеют статус `completed`.
2. Содержат не меньше двух единиц товара.

Для этого используются две логические маски.

```python
import pandas as pd
from io import StringIO

csv_text = """line_item_id,order_id,product,quantity,unit_price,status
2004,5003,Bottle,2,900,completed
2005,5004,Notebook,5,180,completed
2006,5005,Bottle,1,900,cancelled
2007,5006,Mug,1,450,completed
"""

df = pd.read_csv(StringIO(csv_text))

selected_df = df[
    (df["status"] == "completed")
    & (df["quantity"] >= 2)
]

print(selected_df[["line_item_id", "product", "quantity"]])
```

Результат:

```text
   line_item_id   product  quantity
0          2004    Bottle         2
1          2005  Notebook         5
```

Посмотрим, как формируется результат:

| Позиция | Статус completed? | Количество ≥ 2? | Включить? |
|---|---|---|---|
| 2004 | `True` | `True` | Да |
| 2005 | `True` | `True` | Да |
| 2006 | `False` | `False` | Нет |
| 2007 | `True` | `False` | Нет |

Оператор `&` объединяет маски **поэлементно**: строка проходит фильтр, только если оба условия истинны.

В pandas каждое сравнение необходимо заключить в круглые скобки:

```python
(df["status"] == "completed") & (df["quantity"] >= 2)
```

Это обеспечивает правильный порядок вычисления выражения.

**Не используйте здесь обычный Python `and`.** Он предназначен для проверки отдельных логических значений и не заменяет поэлементное объединение масок pandas.

Попытка использовать `and` между такими Series обычно приводит к ошибке о неоднозначности логического значения.

### 3.2. Оператор `|` — логическое «ИЛИ»

Иногда нужно выбрать строки, подходящие хотя бы под одно из условий.

Например, найти все позиции с товарами `Bottle` **или** `Mug`.

```python
import pandas as pd
from io import StringIO

csv_text = """line_item_id,order_id,product,quantity,unit_price,status
2004,5003,Bottle,2,900,completed
2005,5004,Notebook,5,180,completed
2006,5005,Bottle,1,900,cancelled
2007,5006,Mug,1,450,completed
"""

df = pd.read_csv(StringIO(csv_text))

selected_df = df[
    (df["product"] == "Bottle")
    | (df["product"] == "Mug")
]

print(selected_df[["line_item_id", "product", "status"]])
```

Результат включает позиции **2004, 2006 и 2007**.

Почему в него попала отменённая позиция 2006?

Потому что условие проверяет **только название товара**, а не статус.

Это не ошибка pandas. Программа выполнила именно тот фильтр, который мы написали.

**Вывод:** корректный синтаксис не гарантирует, что выбранные записи отвечают нужному бизнес-вопросу.

Для расчётов завершённых продаж надёжнее использовать явное условие `status == "completed"`, а не просто исключать `cancelled`: в других наборах могут встретиться неизвестные статусы.

## 4. Выбираем нужные столбцы

До сих пор мы выбирали строки таблицы. Иногда нужно оставить и только определённые столбцы.

Например, для проверки товарных позиций достаточно показать:

- Название товара.
- Количество.
- Цену единицы.

```python
import pandas as pd
from io import StringIO

csv_text = """product,quantity,unit_price,status
Mug,2,450,completed
Notebook,3,180,completed
Bottle,1,900,cancelled
"""

df = pd.read_csv(StringIO(csv_text))

print(df[["product", "quantity", "unit_price"]])
```

Результат:

```text
    product  quantity  unit_price
0       Mug         2         450
1  Notebook         3         180
2    Bottle         1         900
```

Обратите внимание на **двойные квадратные скобки**:

```python
df[["product", "quantity", "unit_price"]]
```

Внутри находится список названий столбцов. Такой выбор возвращает DataFrame.

Для одного столбца раньше мы использовали:

```python
df["product"]
```

Это выбор одной колонки, обычно возвращающий Series.

**Фильтрация строк** отвечает на вопрос «какие записи нужны?».

**Выбор столбцов** отвечает на вопрос «какие характеристики этих записей нужно показать?».

Их можно применять вместе:

```python
import pandas as pd
from io import StringIO

csv_text = """product,quantity,unit_price,status
Mug,2,450,completed
Notebook,3,180,completed
Bottle,1,900,cancelled
"""

df = pd.read_csv(StringIO(csv_text))

completed_df = df[df["status"] == "completed"]
result = completed_df[["product", "quantity", "unit_price"]]

print(result)
```

Теперь вывод содержит только завершённые позиции и только три нужных столбца.

## 5. Сортировка записей

### 5.1. Что делает `sort_values()`?

**Сортировка** изменяет порядок отображения строк по выбранному столбцу.

Например, можно расположить позиции от самой дешёвой цены к самой дорогой или наоборот.

В pandas для этого используется метод `sort_values()`.

```python
import pandas as pd
from io import StringIO

csv_text = """line_item_id,product,unit_price,status
2004,Bottle,900,completed
2005,Notebook,180,completed
2006,Bottle,900,cancelled
2007,Mug,450,completed
"""

df = pd.read_csv(StringIO(csv_text))

sorted_df = df.sort_values(by="unit_price", ascending=False)

print(sorted_df[["line_item_id", "product", "unit_price"]])
```

Здесь:

- `by="unit_price"` означает «сортировать по цене единицы товара».
- `ascending=False` означает «по убыванию: от большего значения к меньшему».
- `ascending=True` означает сортировку по возрастанию.

В результате цены расположатся так:

**900, 900, 450, 180.**

Обратите внимание: две позиции имеют одинаковую цену 900 рублей. В этом примере **не нужно предполагать, какая из них окажется первой**. Для нас важен порядок цен, а не порядок равных значений.

При использовании показанного метода получается новый отсортированный DataFrame. Исходный `df` остаётся без изменения.

### 5.2. Фильтруем, затем сортируем

Руководитель просит:

> Покажи завершённые товарные позиции от самой высокой цены за единицу до самой низкой.

Здесь нужно выполнить две операции последовательно.

```python
import pandas as pd
from io import StringIO

csv_text = """line_item_id,product,unit_price,status
2004,Bottle,900,completed
2005,Notebook,180,completed
2006,Bottle,900,cancelled
2007,Mug,450,completed
"""

df = pd.read_csv(StringIO(csv_text))

completed_df = df[df["status"] == "completed"]
sorted_df = completed_df.sort_values(
    by="unit_price",
    ascending=False
)

print(sorted_df[["line_item_id", "product", "unit_price"]])
```

Результат:

```text
   line_item_id   product  unit_price
0          2004    Bottle         900
3          2007       Mug         450
1          2005  Notebook         180
```

Что произошло:

1. Из четырёх строк отобраны три завершённые.
2. Отменённая позиция 2006 исключена.
3. Оставшиеся три строки отсортированы по цене.
4. Отменённая позиция **не появилась снова** после сортировки.

### 5.3. Фильтрация и сортировка — разные действия

| Операция | Что меняет | Пример |
|---|---|---|
| Фильтрация | Набор выбранных строк | Только `completed` |
| Сортировка | Порядок выбранных строк | По цене от большей к меньшей |
| Выбор столбцов | Набор отображаемых полей | Только товар и цена |

## 6. Разберём аналитическую задачу

Вернёмся к полному исходному набору интернет-магазина «Северный свет».

Руководитель хочет узнать:

> Сколько завершённых товарных позиций есть в таблице и сколько разных заказов они представляют?

Раньше вы считали эти показатели вручную. Теперь применим фильтрацию pandas.

### Шаг 1. Загружаем данные

```python
import pandas as pd
from io import StringIO

csv_text = """line_item_id,order_id,order_date,customer_id,product,category,quantity,unit_price,status
2001,5001,2026-09-01,C101,Mug,Home,2,450,completed
2002,5001,2026-09-01,C101,Notebook,Stationery,3,180,completed
2003,5002,2026-09-02,C102,Lamp,Home,1,2400,completed
2004,5003,2026-09-02,C103,Bottle,Accessories,2,900,completed
2005,5004,2026-09-03,C104,Notebook,Stationery,5,180,completed
2006,5005,2026-09-04,C105,Bottle,Accessories,1,900,cancelled
2007,5006,2026-09-04,C101,Mug,Home,1,450,completed
2008,5007,2026-09-05,C106,Lamp,Home,1,2400,completed
2009,5007,2026-09-05,C106,Bottle,Accessories,1,900,completed
2010,5008,2026-09-06,C107,Notebook,Stationery,2,180,completed
"""

df = pd.read_csv(StringIO(csv_text))

completed_df = df[df["status"] == "completed"]

print("Всего позиций:", len(df))
print("Завершённых позиций:", len(completed_df))
print("Разных заказов всего:", df["order_id"].nunique())
print(
    "Разных завершённых заказов:",
    completed_df["order_id"].nunique()
)
```

Результат:

```text
Всего позиций: 10
Завершённых позиций: 9
Разных заказов всего: 8
Разных завершённых заказов: 7
```

### Шаг 2. Объясняем результат

В исходном наборе десять строк, но одна позиция относится к отменённому заказу.

После фильтрации остаются **девять завершённых позиций**.

При этом они относятся к **семи различным завершённым заказам**, потому что один заказ может содержать несколько позиций.

Например:

- Заказ 5001 содержит позиции 2001 и 2002.
- Заказ 5007 содержит позиции 2008 и 2009.

Следовательно, количество товарных позиций и количество уникальных заказов — **не одно и то же**.

Общее количество различных заказов без фильтрации равно восьми, поскольку включает и отменённый заказ 5005.

### Шаг 3. Формулируем вывод

«В исходном наборе из десяти товарных позиций девять относятся к завершённым заказам. Эти девять позиций представляют семь уникальных завершённых заказов. Разница возникает потому, что некоторые заказы содержат несколько товаров».

Это пример простого, но уже полноценного анализа: мы **выбрали нужные записи, рассчитали показатели и объяснили их смысл**.
