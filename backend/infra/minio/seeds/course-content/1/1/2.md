# Работа с данными в Python

Данные приходят из разных источников: CSV, JSON, базы данных. В Python всё это
приводится к таблицам и обрабатывается привычными структурами данных.

## Загрузка таблицы

```python
import csv

with open("users.csv", encoding="utf-8") as file:
    rows = list(csv.DictReader(file))

print(len(rows))
```

## Частые операции

| Операция          | Инструмент        |

| Сортировка        | `sorted()`        |
| Группировка       | `collections`     |
