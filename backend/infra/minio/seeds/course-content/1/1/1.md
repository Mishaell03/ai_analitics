# Переменные и типы данных

Python — динамически типизированный язык: тип переменной определяется в момент
присваивания значения, а не при объявлении.

## Базовые типы

| Тип      | Описание        | Пример          |
|----------|-----------------|-----------------|
| `int`    | Целое число     | `42`            |
| `float`  | Число с точкой  | `3.14`          |
| `str`    | Строка          | `"привет"`      |
| `bool`   | Логическое      | `True`          |
| `list`   | Список          | `[1, 2, 3]`     |
| `dict`   | Словарь         | `{"key": 1}`    |

## Переменные

```python
name = "Иван"
age = 30

print(f"{name}, тебе {age} лет")
```

Имена переменных записываются в `snake_case`, константы — в `UPPER_CASE`.
