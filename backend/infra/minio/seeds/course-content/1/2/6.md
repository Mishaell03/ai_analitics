## 1. Несколько значений — один список

Раньше для каждого значения мы создавали отдельную переменную:

```python
quantity_1 = 2
quantity_2 = 5
quantity_3 = 1
```

Так можно работать с тремя позициями, но с десятками записей код станет длинным. **Список** позволяет хранить несколько значений под одним именем:

```python
quantities = [2, 5, 1]
print(quantities)
```

Результат:

```text
[2, 5, 1]
```

В списке три **элемента**. Квадратные скобки `[]` обозначают границы списка, запятые разделяют элементы, а порядок элементов сохраняется.

Здесь значения соответствуют количествам в позициях 2004, 2005 и 2006 магазина «Северный свет». Последняя позиция отменена. Поэтому **сумма всех количеств в этом списке ещё не означает количество проданных единиц**: для продаж нужно учитывать статус.

### 1.1. Индексы начинаются с нуля

Каждый элемент имеет номер позиции — **индекс**. В Python первый элемент имеет индекс `0`.

| Индекс | `0` | `1` | `2` |
|---|---:|---:|---:|
| Значение | 2 | 5 | 1 |

```python
quantities = [2, 5, 1]

print(quantities[0])
print(quantities[1])
print(quantities[2])
```

Результат:

```text
2
5
1
```

Выражение `quantities[1]` означает «элемент с индексом 1», то есть **второй** элемент. Индекс — не само значение: `quantities[1]` равно 5, а не 1.

### 1.2. Сколько элементов в списке?

Функция `len()` возвращает количество элементов:

```python
quantities = [2, 5, 1]
print(len(quantities))
```

Результат:

```text
3
```

`len()` отвечает на вопрос «сколько элементов?», а не «какова их сумма?». Для нашего списка длина равна 3, сумма значений — 8.

Если попробовать обратиться к `quantities[3]`, Python выдаст `IndexError`: четвёртого элемента здесь нет. Допустимые индексы этого списка — `0`, `1` и `2`.

**Попробуйте:** прежде чем запускать следующий код, определите, какое число он напечатает:

```python
quantities = [4, 1, 6]
print(quantities[2])
```

## 2. Первый цикл `for`

### 2.1. Выполняем действие для каждого элемента

Если нужно вывести все количества, можно написать три команды `print()`. Но цикл делает то же самое без повторения команды:

```python
quantities = [2, 5, 1]

for quantity in quantities:
    print(quantity)
```

Результат:

```text
2
5
1
```

Разберём строку `for quantity in quantities:`:

- `for` — начало цикла.
- `quantities` — список, по которому мы проходим.
- `quantity` — переменная, которая по очереди получает значения элементов.
- `in` связывает переменную со списком: «для каждого `quantity` из `quantities`».
- `:` начинает блок цикла; четыре пробела отмечают команду, которая повторяется.

Сначала `quantity` равно 2 и выполняется `print(quantity)`. Затем равно 5, затем 1. После третьего элемента цикл заканчивается.

Цикл не изменяет исходные значения списка. Название переменной цикла можно выбрать самостоятельно; главное, чтобы оно было понятным.

### 2.2. Накапливаем сумму

Теперь найдём сумму количеств. Для этого нужна переменная-**накопитель**: мы начинаем с нуля и прибавляем каждое очередное значение.

```python
quantities = [2, 5, 1]
total_quantity = 0

for quantity in quantities:
    total_quantity = total_quantity + quantity

print("Сумма количеств:", total_quantity)
```

Результат:

```text
Сумма количеств: 8
```

Проследим изменения накопителя:

| Шаг | Текущее `quantity` | `total_quantity` после сложения |
|---|---:|---:|
| До цикла | — | 0 |
| Первый элемент | 2 | 2 |
| Второй элемент | 5 | 7 |
| Третий элемент | 1 | 8 |

Строка `total_quantity = total_quantity + quantity` означает: «возьми прежнюю сумму, добавь очередное значение и сохрани новый результат». Это присваивание, а не математическое уравнение.

Последний `print()` стоит **без отступа**, поэтому выполняется один раз после завершения цикла.

Ещё раз: число 8 — сумма полей `quantity` во всех трёх позициях, **включая отменённую**. Ниже добавим проверку статуса.

### 2.3. Считаем записи, отвечающие условию

Чтобы посчитать не значения, а количество подходящих записей, будем увеличивать счётчик на 1:

```python
statuses = ["completed", "cancelled", "completed"]
completed_count = 0

for status in statuses:
    if status == "completed":
        completed_count = completed_count + 1

print("Завершённых позиций:", completed_count)
```

Результат:

```text
Завершённых позиций: 2
```

**Разница ролей:** `for` последовательно рассматривает элементы, `if` решает, подходит ли текущий элемент, а счётчик запоминает, сколько раз условие выполнилось.

## 3. Разбор: цикл и условия для анализа

### 3.1. Проверяем допустимость количеств

Рассмотрим **отдельный учебный список с ошибочными значениями**. Это не изменение исходной таблицы магазина:

```python
quantities = [2, 0, 5, -1]
valid_count = 0
valid_total = 0

for quantity in quantities:
    if quantity > 0:
        valid_count = valid_count + 1
        valid_total = valid_total + quantity

print("Подходящих значений:", valid_count)
print("Их сумма:", valid_total)
```

Результат:

```text
Подходящих значений: 2
Их сумма: 7
```

Ноль и отрицательное число не соответствуют правилу `quantity > 0`, поэтому в расчёт не попали. **Это демонстрация отбора значений, а не рекомендация молча удалять неправильные строки:** в реальном анализе такие данные требуют проверки.

### 3.2. Разберём пример с предсказанием результата

Рассмотрим отдельный тренировочный список статусов:

```python
statuses = ["completed", "cancelled", "completed", "completed"]
completed_count = 0
cancelled_count = 0

for status in statuses:
    if status == "completed":
        completed_count = completed_count + 1
    elif status == "cancelled":
        cancelled_count = cancelled_count + 1

print("Завершённых:", completed_count)
print("Отменённых:", cancelled_count)
```

**До запуска** предскажите две итоговые величины. Затем сравните их с результатом:

```text
Завершённых: 3
Отменённых: 1
```

Разбор по шагам:

| Текущий статус | Завершённых после шага | Отменённых после шага |
|---|---:|---:|
| До цикла | 0 | 0 |
| `completed` | 1 | 0 |
| `cancelled` | 1 | 1 |
| `completed` | 2 | 1 |
| `completed` | 3 | 1 |

Каждая итерация проверяет **один** статус. В цепочке `if` / `elif` выполняется только подходящая ветка. При неизвестном статусе в этом примере ни один счётчик не изменится; при работе с такими значениями необходимо предусмотреть отдельное предупреждение.

### 3.3. Когда одна запись содержит несколько полей

До сих пор в списке были только количества или только статусы. Но товарная позиция имеет несколько характеристик: статус, количество и цену.

В простом учебном примере можно представить каждую запись **внутренним списком**, а несколько записей — **внешним списком**:

```python
items = [
    ["completed", 2, 900],
    ["cancelled", 1, 900],
]

print(items[0])
print(items[0][0])
print(items[0][1])
print(items[0][2])
```

Результат:

```text
['completed', 2, 900]
completed
2
900
```

`items[0]` — первая **запись целиком**. Затем второй индекс указывает на поле *внутри* выбранной записи:

| Выражение | Что получаем |
|---|---|
| `items[0][0]` | Статус первой записи: `completed` |
| `items[0][1]` | Количество первой записи: `2` |
| `items[0][2]` | Цена первой записи: `900` |
| `items[1][0]` | Статус второй записи: `cancelled` |

**Порядок полей фиксирован:** в каждом внутреннем списке сначала статус, затем количество, затем цена. Это упрощённое представление товарных позиций, а **не** структура исходной таблицы `order_items` с девятью столбцами.

Цикл может пройти по записям и прочитать нужные поля:

```python
items = [
    ["completed", 2, 900],
    ["cancelled", 1, 900],
]

for item in items:
    status = item[0]
    quantity = item[1]
    unit_price = item[2]
    print(status, quantity, unit_price)
```

Результат:

```text
completed 2 900
cancelled 1 900
```

На каждой итерации переменная `item` содержит один внутренний список. Для доступа к его полям достаточно одного индекса: `item[0]`, `item[1]`, `item[2]`.

В следующем задании вы самостоятельно объедините этот способ чтения записей с накопителем и условиями для расчёта выручки.

## 4. Типичные ошибки при работе со списками и циклами

**1. Нет двоеточия после `for`.** После `for quantity in quantities` нужно поставить `:`. Иначе возникает `SyntaxError`.

**2. Неверный отступ.** Команды, повторяемые циклом, должны иметь отступ. Если вынести проверку `if` за пределы цикла, она не будет проверять каждую запись.

**3. Неверный индекс.** У списка `[2, 5, 1]` нет элемента с индексом `3`: возникает `IndexError`. Индексы начинаются с нуля.

**4. Индекс путают со значением.** В `quantities = [2, 5, 1]` индекс `1` обозначает элемент со значением `5`, а не количество `1`.

**5. Накопитель не создан.** Если использовать `total = total + quantity` до присваивания начального значения `total`, возникнет `NameError`.

**6. Накопитель случайно обнуляют внутри цикла.** Эта программа запускается без ошибки, но считает неправильно:

```python
quantities = [2, 5, 1]

for quantity in quantities:
    total = 0
    total = total + quantity

print(total)
```

Результат:

```text
1
```

На каждом шаге `total` заново становится нулём. К концу цикла в нём остаётся только последнее количество — 1. Чтобы получить сумму, присваивание `total = 0` нужно разместить **перед циклом**.

**7. Выручку прибавляют вне проверки статуса.** Если вычисление и накопление выручки не находятся внутри ветки `if status == "completed":`, отменённые позиции могут ошибочно попасть в итог. Код при этом может выполняться без сообщений об ошибке.

**Обсудите с AI-наставником.** Если ваш накопитель даёт неожиданный результат, покажите наставнику короткий фрагмент кода и попросите проследить, как меняется переменная на каждой итерации. Пусть сначала объяснит причину, а не пишет за вас решение самостоятельного задания.

## 7. Итоги урока

Сегодня вы перешли от отдельных значений к обработке нескольких записей.

Теперь вы знаете, как:

- Объединять значения в список и получать элементы по индексам.
- Определять длину списка с помощью `len()`.
- Выполнять одну последовательность команд для каждого элемента с помощью `for`.
- Накапливать сумму и подсчитывать подходящие записи.
- Использовать `if` внутри цикла, чтобы применять бизнес-правила.
- Читать упрощённые товарные записи, представленные вложенными списками.
- Исключать отменённые и неизвестные статусы из расчёта учебной выручки.

**Главный результат:** теперь вам не нужно переписывать одинаковое условие для каждой товарной позиции. Цикл повторяет обработку, условие выбирает подходящие записи, а накопитель сохраняет итог. Именно так начинаются программы для анализа небольших наборов данных.
