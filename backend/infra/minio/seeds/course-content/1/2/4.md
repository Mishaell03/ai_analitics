## 1. Знакомство с Python

### 1.1. Что такое Python?

**Python** — это язык программирования. С его помощью человек записывает инструкции, которые компьютер может выполнить.

Например, компьютер можно попросить:

- Сложить несколько чисел.
- Рассчитать стоимость товаров.
- Обработать множество записей.
- Найти ошибки в данных.
- Подготовить результаты для анализа.

Аналитики используют Python, чтобы автоматизировать действия, которые вручную занимали бы много времени.

Сегодня мы начнём с небольших программ. В дальнейшем вы научитесь работать с целыми таблицами.

### 1.2. Где будем писать код?

На нашей образовательной платформе есть встроенная среда выполнения Python.

Вам не нужно устанавливать Python на компьютер, настраивать программы или скачивать дополнительные библиотеки.

В специальном поле можно написать код, запустить его и увидеть результат.

Обычно работа выглядит так:

1. Вы пишете несколько строк Python-кода.
2. Запускаете выполнение.
3. Среда выполняет инструкции.
4. Вы изучаете результат или сообщение об ошибке.

**Важно:** каждое выполнение кода рассматривайте как отдельный запуск программы. Если вы хотите использовать переменную, создайте её в том же фрагменте кода. Не рассчитывайте, что значения из предыдущего запуска сохранились.

Python-песочница не подключается к базе данных магазина. В этом уроке мы самостоятельно записываем учебные значения непосредственно в коде.

### 1.4. Python умеет считать

Теперь напишем:

```python
print(2 + 3)
print(2 * 450)
```

Результат:

```text
5
900
```

Здесь:

- `+` означает сложение.
- `*` означает умножение.

В Python для умножения используется звёздочка `*`, а не математический знак `×`.

Обратите внимание на различие:

```python
print("2 + 3")
print(2 + 3)
```

Результат:

```text
2 + 3
5
```

В первом случае Python вывел текст без вычислений. Во втором — сложил два числа.

**Исходный код** — инструкции, которые вы написали. **Результат выполнения** — то, что программа вывела после запуска.

## 2. Переменные: как сохранять значения

Представьте, что магазин «Северный свет» продаёт две кружки по 450 рублей.

Мы уже можем рассчитать стоимость:

```python
print(2 * 450)
```

Но если чисел станет много, будет сложно помнить, что именно они обозначают.

Для этого нужны переменные.

### 2.1. Создаём переменные

**Переменная** — это имя, с которым связано определённое значение.

```python
quantity = 2
unit_price = 450

print(quantity)
print(unit_price)
```

Результат:

```text
2
450
```

Разберём строки:

- `quantity = 2` — переменной `quantity` присваивается значение 2.
- `unit_price = 450` — переменной `unit_price` присваивается значение 450.
- `print(quantity)` — выводится значение переменной.

Знак `=` в Python используется для **присваивания значения**, а не для записи математического равенства.

Название переменной должно помогать понять её назначение. Например, `quantity` гораздо понятнее, чем `x`.

### 2.2. Вычисления с переменными

Теперь рассчитаем стоимость товарной позиции.

```python
quantity = 2
unit_price = 450

revenue = quantity * unit_price

print("Выручка позиции:", revenue)
```

Результат:

```text
Выручка позиции: 900
```

Программа выполняется последовательно:

1. Сохраняет количество товара.
2. Сохраняет цену одной единицы.
3. Умножает количество на цену.
4. Сохраняет результат в `revenue`.
5. Выводит результат.

В нашем учебном магазине такой расчёт соответствует правилу:

**Учебная выручка позиции = количество × цена единицы товара.**

Но в общую учебную выручку магазина включаются только завершённые позиции со статусом `completed`. Отменённые позиции необходимо исключать.

### 2.3. Изменяем значение переменной

Значение переменной можно изменить.

```python
quantity = 2
unit_price = 450

print(quantity * unit_price)

quantity = 3

print(quantity * unit_price)
```

Результат:

```text
900
1350
```

Что произошло?

Сначала `quantity` было равно 2. Затем мы присвоили этой переменной новое значение 3.

Повторное вычисление использовало уже новое количество.

Если результат ранее был сохранён в отдельную переменную `revenue`, её значение не изменится автоматически: для нового расчёта нужно ещё раз выполнить присваивание `revenue = quantity * unit_price`.

Это полезно, когда аналитик проверяет разные варианты исходных данных.

### 2.4. Комментарии в коде

Иногда нужно пояснить, зачем выполняется определённая строка.

Для этого используют комментарии.

```python
# Количество кружек
quantity = 2

# Цена одной кружки
unit_price = 450

# Рассчитываем учебную выручку позиции
revenue = quantity * unit_price

print(revenue)
```

Результат:

```text
900
```

Всё, что находится после символа `#` в строке, Python воспринимает как комментарий и не выполняет.

Комментарии помогают читать код, но их не нужно писать после каждой очевидной операции.

## 3. Основные типы данных

В предыдущем уроке мы уже обсуждали, что таблицы содержат числа, текст и даты.

В Python тоже есть разные типы значений.

Сегодня познакомимся с тремя основными типами.

| Тип Python | Назначение | Пример |
|---|---|---|
| `int` | Целое число | `2` |
| `float` | Число с дробной частью | `450.50` |
| `str` | Текстовая строка | `"Mug"` |

### 3.1. Целые числа — `int`

```python
quantity = 2
order_count = 7
```

Это целые числа.

С ними можно выполнять арифметические операции.

### 3.2. Числа с дробной частью — `float`

```python
unit_price = 450.50
```

Такое значение относится к типу `float`.

В Python дробная часть числа отделяется **точкой**, а не запятой.

### 3.3. Текст — `str`

```python
product = "Mug"
category = "Home"
```

Текст помещается в кавычки.

Число, записанное в кавычках, тоже становится текстом:

```python
quantity = 2
quantity_text = "2"
```

Хотя оба значения выглядят похоже, Python воспринимает их по-разному.

### 3.4. Как узнать тип значения?

Для этого существует встроенная функция `type()`.

```python
quantity = 2
unit_price = 450.50
product = "Mug"

print(type(quantity))
print(type(unit_price))
print(type(product))
```

Результат:

```text
<class 'int'>
<class 'float'>
<class 'str'>
```

Запись `<class 'int'>` означает, что Python определил значение как целое число. Слово `class` здесь — часть стандартного представления типа; отдельно изучать его пока не требуется.

### 3.5. Почему текст и число — не одно и то же?

Посмотрите на этот пример:

```python
quantity = 2
quantity_text = "2"

print(quantity + 3)
print(quantity_text + "3")
```

Результат:

```text
5
23
```

Первое выражение складывает числа.

Второе **соединяет два текстовых значения**, поэтому получается `"23"`, а не 5.

Если мы получили число в виде текста, иногда его можно преобразовать с помощью `int()`.

```python
quantity_text = "2"

quantity = int(quantity_text)

print(quantity + 3)
```

Результат:

```text
5
```

Это работает, потому что текст `"2"` действительно обозначает целое число. Если передать `int()` произвольное слово, например `"два"`, Python сообщит об ошибке.

Пока достаточно помнить главное: **не все значения, которые выглядят как числа, являются числами для Python.**

## 4. Арифметические операции

Python поддерживает привычные арифметические действия.

| Операция | Символ | Пример |
|---|---|---|
| Сложение | `+` | `7 + 2` |
| Вычитание | `-` | `7 - 2` |
| Умножение | `*` | `7 * 2` |
| Деление | `/` | `7 / 2` |

Проверим их:

```python
print(7 + 2)
print(7 - 2)
print(7 * 2)
print(7 / 2)
```

Результат:

```text
9
5
14
3.5
```

При обычном делении `/` Python возвращает результат типа `float`, даже если число делится без остатка. Например, `900 / 2` даст `450.0`.

### Порядок действий

Python соблюдает математический порядок операций.

Умножение и деление выполняются раньше сложения и вычитания.

```python
print(10 + 2 * 3)
print((10 + 2) * 3)
```

Результат:

```text
16
36
```

В первом выражении сначала выполняется `2 * 3`, затем прибавляется 10.

Во втором выражении сначала вычисляется сумма в скобках, а затем результат умножается на 3.

**Совет:** используйте скобки, когда хотите явно показать порядок вычислений.

## 5. Разобранный пример: выручка заказа

Вернёмся к исходным данным магазина «Северный свет».

Заказ **5001** содержит две завершённые товарные позиции:

| Товар | Количество | Цена, руб. |
|---|---:|---:|
| Mug | 2 | 450 |
| Notebook | 3 | 180 |

Наша задача — рассчитать учебную выручку заказа.

### Шаг 1. Сохраняем исходные значения

```python
mug_quantity = 2
mug_price = 450

notebook_quantity = 3
notebook_price = 180
```

Мы используем отдельные переменные для двух товаров, чтобы не перепутать их количества и цены.

### Шаг 2. Рассчитываем выручку позиций

```python
mug_quantity = 2
mug_price = 450

notebook_quantity = 3
notebook_price = 180

mug_revenue = mug_quantity * mug_price
notebook_revenue = notebook_quantity * notebook_price

print(mug_revenue)
print(notebook_revenue)
```

Результат:

```text
900
540
```

Первая позиция даёт 900 рублей учебной выручки, вторая — 540 рублей.

Обратите внимание: мы повторили присваивания исходных значений, чтобы этот пример можно было запускать отдельно.

### Шаг 3. Рассчитываем выручку заказа целиком

```python
mug_quantity = 2
mug_price = 450

notebook_quantity = 3
notebook_price = 180

mug_revenue = mug_quantity * mug_price
notebook_revenue = notebook_quantity * notebook_price

order_revenue = mug_revenue + notebook_revenue

print("Кружки:", mug_revenue)
print("Блокноты:", notebook_revenue)
print("Выручка заказа:", order_revenue)
```

Результат:

```text
Кружки: 900
Блокноты: 540
Выручка заказа: 1440
```

**Итог:** учебная выручка заказа 5001 составляет **1440 рублей**.

Она совпадает с нашим ручным расчётом из предыдущих уроков.

Обратите внимание, что Python не получил эти данные автоматически из базы. Мы вручную указали известные значения в переменных.

### Зачем это нужно?

Пока программа рассчитывает показатель всего для двух позиций.

Но вы уже освоили основную идею: **данные можно сохранить в переменных, обработать с помощью выражений и вывести результат.**

Позднее мы научимся применять похожие расчёты ко множеству записей.

## 6. Практика с поддержкой: что изменится при другом количестве?

Рассмотрим **отдельный тренировочный пример**, не входящий в основную таблицу магазина.

Допустим, четыре единицы товара продаются по 320 рублей.

Нужно рассчитать учебную выручку позиции, а затем проверить, как она изменится при увеличении количества до пяти единиц.

Сначала определим переменные:

- `quantity` — количество.
- `unit_price` — цена единицы.
- `revenue` — первоначальная выручка.
- `new_revenue` — выручка после изменения количества.

**Перед запуском попробуйте предсказать:**

- Какую выручку даст количество 4?
- Какой будет выручка при количестве 5?
- На сколько рублей изменится результат?

### Разбор решения

```python
quantity = 4
unit_price = 320

revenue = quantity * unit_price
print("Было:", revenue)

quantity = 5

new_revenue = quantity * unit_price
print("Стало:", new_revenue)

print("Изменение:", new_revenue - revenue)
```

Результат:

```text
Было: 1280
Стало: 1600
Изменение: 320
```

**Что важно понять:**

1. Переменная `revenue` сохраняет первоначальный результат — 1280 рублей.
2. После изменения `quantity` мы выполняем новый расчёт.
3. Переменная `new_revenue` хранит новое значение — 1600 рублей.
4. Разность показывает изменение выручки — 320 рублей.

Изменение одного исходного значения может повлиять на итоговую метрику.

Это один из простейших способов проверки расчётов.

## 7. Первые ошибки в Python: как их понимать

Ошибки во время программирования — обычная часть обучения.

Важнее не избегать их любой ценой, а научиться разбираться в причинах.

### Ошибка 1. Забыли кавычки

Например, запись `print(Привет)` заставит Python искать переменную с именем `Привет`.

Если такой переменной нет, появится ошибка `NameError`.

Для вывода текста нужно использовать кавычки:

```python
print("Привет")
```

### Ошибка 2. Перепутали название переменной

Если вы создали переменную `quantity`, а затем написали `quanity`, Python не найдёт нужное имя.

Исправленный вариант:

```python
quantity = 2

print(quantity)
```

Результат:

```text
2
```

**Подсказка:** при ошибке `NameError` сначала проверьте написание имени и убедитесь, что переменная создана до использования.

### Ошибка 3. Пытаемся сложить число и текст

Выражение `2 + "2"` вызывает ошибку `TypeError`, потому что Python не может выполнить такое сложение числа с текстом.

Если текст содержит запись целого числа, его можно преобразовать:

```python
quantity = 2
quantity_text = "2"

print(quantity + int(quantity_text))
```

Результат:

```text
4
```

### Ошибка 4. Неправильно записали арифметическое выражение

В Python запись `quantity unit_price` без знака операции вызовет синтаксическую ошибку `SyntaxError`.

Умножение записывается так:

```python
quantity = 2
unit_price = 450

revenue = quantity * unit_price

print(revenue)
```

Результат:

```text
900
```

А вот деление вместо умножения может не вызвать технической ошибки, но даст неправильный для нашей задачи расчёт.

**Не все ошибки сопровождаются сообщением Python.** Иногда программа выполняется, но использует неверную формулу.

### Как исследовать ошибку

Если программа не работает:

1. Прочитайте текст сообщения об ошибке.
2. Найдите строку, на которую указывает Python.
3. Проверьте имена переменных, кавычки и знаки операций.
4. Убедитесь, что значения имеют подходящие типы.
5. Исправьте одну предполагаемую причину и запустите код повторно.

### Обсудите с AI-наставником

Если ошибка непонятна, можно обратиться к AI-наставнику:

> Я изучаю Python с нуля. Помоги разобраться, что означает моя ошибка. Объясни сообщение простыми словами, подскажи, что проверить в коде, но не пиши за меня готовое решение.

Приложите к вопросу свой код и текст ошибки. Так наставнику будет проще объяснить причину.
