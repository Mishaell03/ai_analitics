## 1. Первое знакомство с условиями

### 1.1. Зачем программе принимать решения?

Представьте, что интернет-магазин «Северный свет» передаёт аналитику данные о продажах.

Согласно правилам нашего магазина:

- Завершённые позиции (`completed`) учитываются при расчёте учебной выручки.
- Отменённые позиции (`cancelled`) не учитываются.
- Количество товара должно быть положительным целым числом.
- Цена единицы товара не может быть отрицательной.

Ранее вы применяли эти правила вручную. Теперь научимся записывать их на Python.

**Условие** — это проверка, результатом которой является «истина» или «ложь».

Например:

- Количество товара больше нуля?
- Статус заказа равен `completed`?
- Цена неотрицательная?

Python может проверить такие утверждения и выбрать действие в зависимости от результата.

### 1.2. Что такое `True` и `False`?

В Python результат логической проверки представлен двумя специальными значениями:

- `True` — истина, условие выполняется.
- `False` — ложь, условие не выполняется.

Посмотрите на программу:

```python
quantity = 3

print(quantity > 0)
print(quantity == 3)
print(quantity < 3)
```

Результат:

```text
True
True
False
```

Разберём каждую проверку:

1. `quantity > 0` — число 3 больше нуля. Это правда.
2. `quantity == 3` — значение переменной равно 3. Это правда.
3. `quantity < 3` — число 3 меньше 3. Это неправда.

`True` и `False` — не обычные текстовые строки. Их не нужно заключать в кавычки.

### 1.3. Операторы сравнения

| Оператор | Значение | Пример |
|---|---|---|
| `==` | Равно | `quantity == 3` |
| `!=` | Не равно | `status != "cancelled"` |
| `>` | Больше | `quantity > 0` |
| `<` | Меньше | `unit_price < 0` |
| `>=` | Больше или равно | `quantity >= 1` |
| `<=` | Меньше или равно | `quantity <= 10` |

Например:

```python
quantity = 3

print(quantity >= 3)
print(quantity != 3)
print(quantity <= 2)
```

Результат:

```text
True
False
False
```

Обратите внимание на разницу между двумя символами:

- `=` — присвоение: `quantity = 3`.
- `==` — сравнение: `quantity == 3`.

Это разные операции.

## 2. Как Python выбирает действие

### 2.1. Оператор `if`

Ключевое слово `if` переводится как «если».

Оно позволяет выполнить определённые инструкции **только тогда, когда условие истинно**.

Рассмотрим пример:

```python
quantity = 2

if quantity > 0:
    print("Количество положительное")

print("Проверка завершена")
```

Результат:

```text
Количество положительное
Проверка завершена
```

Что происходит:

1. Python сохраняет значение `quantity = 2`.
2. Проверяет условие `quantity > 0`.
3. Получает `True`.
4. Выполняет строку с отступом.
5. Затем выполняет последнюю строку программы.

Теперь проверим другой случай:

```python
quantity = 0

if quantity > 0:
    print("Количество положительное")

print("Проверка завершена")
```

Результат:

```text
Проверка завершена
```

Поскольку условие ложно, Python пропускает строку внутри `if`.

Последняя команда выполняется в любом случае, поскольку она не находится внутри условного блока.

### 2.2. Двоеточие и отступы

Обратите внимание на оформление:

```python
quantity = 2

if quantity > 0:
    print("Количество подходит")
```

Здесь важны две детали.

**Двоеточие `:`** показывает, что далее начинается блок инструкций.

**Отступ** определяет, какие строки относятся к условию.

Обычно используются четыре пробела.

Python воспринимает отступы как часть синтаксиса языка. Если они расставлены неправильно, программа может не запуститься или выполнить не то действие, которое вы задумали.

### 2.3. Выбираем между двумя вариантами: `if` и `else`

Иногда нам нужно выполнить одно действие при истинном условии и другое — при ложном.

Для этого существует `else` — «иначе».

Используем реальную завершённую позицию 2004 магазина «Северный свет»:

- Товар: Bottle.
- Количество: 2.
- Цена: 900 рублей.
- Статус: `completed`.

```python
status = "completed"
quantity = 2
unit_price = 900

if status == "completed":
    revenue = quantity * unit_price
else:
    revenue = 0

print("Учебная выручка:", revenue)
```

Результат:

```text
Учебная выручка: 1800
```

Программа проверила статус.

Поскольку он равен `completed`, выполнена первая ветка: количество умножено на цену.

Теперь рассмотрим отменённую позицию 2006:

```python
status = "cancelled"
quantity = 1
unit_price = 900

if status == "completed":
    revenue = quantity * unit_price
else:
    revenue = 0

print("Учебная выручка:", revenue)
```

Результат:

```text
Учебная выручка: 0
```

Условие оказалось ложным, поэтому программа выполнила ветку `else`.

**Важно:** это простой пример для двух заранее известных статусов. Если в данных встречаются неизвестные статусы, нельзя автоматически считать их обычной отменой. Далее научимся обрабатывать такой случай отдельно.

### 2.4. Несколько вариантов: `if`, `elif`, `else`

Представим, что статус записи может быть:

- `completed` — завершён.
- `cancelled` — отменён.
- Неизвестным — значение требует проверки.

Для этого подходит `elif`, сокращение от *else if* — «иначе, если».

Рассмотрим **отдельный имитированный учебный случай** со статусом `processing`. Это значение не входит в список допустимых статусов нашей основной таблицы.

```python
status = "processing"

if status == "completed":
    print("Учитываем завершённую позицию")
elif status == "cancelled":
    print("Не учитываем отменённую позицию")
else:
    print("Неизвестный статус: требуется проверка")
```

![m_72e62512f7eb46e3](asset:m_72e62512f7eb46e3)

Результат:

```text
Неизвестный статус: требуется проверка
```

Python последовательно проверяет условия:

1. Статус равен `completed`? Нет.
2. Статус равен `cancelled`? Нет.
3. Подходящего условия не найдено — выполняется `else`.

**Когда одна из веток выполнена, остальные ветки этой цепочки пропускаются.**

Именно поэтому `if`, `elif` и `else` удобны для выбора одного из нескольких взаимоисключающих вариантов.

### 2.5. Объединяем условия: `and` и `or`

Иногда одной проверки недостаточно.

Например, мы хотим убедиться, что товарная позиция завершена, количество положительно, а цена неотрицательная.

Для объединения условий используются логические операторы.

**`and` — «и»**

Все объединённые условия должны быть истинными.

```python
status = "completed"
quantity = 2
unit_price = 900

print(status == "completed" and quantity > 0 and unit_price >= 0)
```

Результат:

```text
True
```

Все три проверки выполняются.

Если хотя бы одна окажется ложной, общее условие с `and` будет ложным.

**`or` — «или»**

Достаточно, чтобы хотя бы одно условие было истинным.

```python
status = "cancelled"

print(status == "completed" or status == "cancelled")
```

Результат:

```text
True
```

Статус не равен `completed`, но равен `cancelled`.

Значит, он входит в два допустимых значения нашей учебной модели.

Для наглядности:

| Условие A | Условие B | `A and B` | `A or B` |
|---|---|---|---|
| `True` | `True` | `True` | `True` |
| `True` | `False` | `False` | `True` |
| `False` | `True` | `False` | `True` |
| `False` | `False` | `False` | `False` |

Полезно разделять две задачи:

- **Проверка допустимости:** статус равен `completed` **или** `cancelled`.
- **Включение в учебную выручку:** статус должен быть именно `completed`.

Допустимый статус `cancelled` не означает, что позиция должна участвовать в расчёте выручки.

## 3. Разберём практический пример

### 3.1. Проверяем запись перед расчётом

Представьте, что нам нужно обработать товарную позицию магазина.

Перед вычислением учебной выручки важно убедиться:

1. Количество больше нуля.
2. Цена неотрицательная.
3. Статус позволяет определить, учитывать позицию или нет.

Используем исходную позицию 2006: отменённую бутылку по цене 900 рублей.

Перед запуском подумайте:

- Нарушает ли количество правило положительности?
- Нарушает ли цена правило неотрицательности?
- Какую выручку должна дать отменённая позиция?

### Разбор решения

```python
status = "cancelled"
quantity = 1
unit_price = 900

if quantity <= 0 or unit_price < 0:
    print("Проверьте количество и цену")
elif status == "completed":
    print("Учебная выручка:", quantity * unit_price)
elif status == "cancelled":
    print("Учебная выручка: 0")
else:
    print("Неизвестный статус: требуется проверка")
```

Результат:

```text
Учебная выручка: 0
```

**Почему программа сработала именно так?**

Сначала она проверила, не нарушены ли правила количества и цены:

- `quantity <= 0` — ложь, поскольку количество равно 1.
- `unit_price < 0` — ложь, поскольку цена равна 900.

Общее выражение с `or` ложно, поэтому программа переходит к следующей проверке.

Статус не равен `completed`, но равен `cancelled`. Следовательно, выполняется соответствующая ветка `elif`.

Выручка отменённой позиции не учитывается.

Теперь рассмотрим позицию 2004 с теми же правилами, но другими исходными значениями.

```python
status = "completed"
quantity = 2
unit_price = 900

if quantity <= 0 or unit_price < 0:
    print("Проверьте количество и цену")
elif status == "completed":
    print("Учебная выручка:", quantity * unit_price)
elif status == "cancelled":
    print("Учебная выручка: 0")
else:
    print("Неизвестный статус: требуется проверка")
```

Результат:

```text
Учебная выручка: 1800
```

Теперь программа учитывает позицию, поскольку количество и цена допустимы, а статус равен `completed`.

Такой подход позволяет не только выполнять арифметические действия, но и применять правила анализа.

### 3.2. Типичные ошибки в условиях

Ошибки в условиях могут помешать запуску программы или привести к неверному результату.

**Ошибка 1. Использование `=` вместо `==`**

Неверная запись: `if status = "completed":`

Здесь использован знак присваивания вместо сравнения.

Python выдаст `SyntaxError`. Для проверки равенства нужно использовать `==`.

**Ошибка 2. Пропущено двоеточие**

Неверная запись: `if quantity > 0`

После условия необходимо написать `:`.

**Ошибка 3. Отсутствует отступ**

После строки `if quantity > 0:` инструкции, относящиеся к условию, должны иметь отступ.

Иначе может возникнуть `IndentationError`.

**Ошибка 4. Сравнение текста с числом**

Например, если `quantity = "3"`, проверка `quantity > 0` приведёт к `TypeError`.

В переменной хранится текст, а программа пытается сравнить его с числом.

Если вы уверены, что строка содержит корректную запись целого числа, можно использовать `int()`.

**Ошибка 5. Неправильное расположение вычисления**

Посмотрите на корректный вариант:

```python
status = "cancelled"
quantity = 1
unit_price = 900

revenue = 0

if status == "completed":
    revenue = quantity * unit_price

print(revenue)
```

Результат:

```text
0
```

Если по ошибке убрать отступ у строки `revenue = quantity * unit_price`, она будет выполняться независимо от `if`.

Тогда отменённая позиция ошибочно попадёт в расчёт.

**Ошибка 6. Логически неверная проверка**

Даже правильно написанная программа может принимать неправильные решения.

Например, условие `status != "cancelled"` пропускает не только `completed`, но и неизвестные статусы вроде `processing`.

Для включения позиции в выручку безопаснее явно проверять `status == "completed"`.
