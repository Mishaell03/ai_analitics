## 1. Какой вопрос решает график?

Представьте два вопроса о розничных продажах за январь–март 2025 года:

- **Какая товарная категория принесла больше учебной выручки?** Нужно сравнить категории. Подходит **столбчатая диаграмма**: одна категория — один столбец.
- **Как изменялась выручка от января к марту?** Нужно увидеть последовательность во времени. Подходит **линейный график**: одна точка — один месяц, соседние точки соединены линией.

Таблица полезнее графика, если читателю требуется найти точное значение, проверить идентификатор или просмотреть много отдельных записей. График особенно удобен для сравнения и первого выявления закономерностей.

| Сопоставить выручку категорий | Столбцы | Высоты (или длины) легко сравнить |

## 2. Первые диаграммы: `matplotlib`

**matplotlib** — библиотека Python для построения графиков. Чаще всего мы используем её модуль `pyplot` под коротким именем `plt`:

```python
import pandas as pd
import matplotlib.pyplot as plt
from io import StringIO
```

Обычная последовательность работы:

1. Получить и проверить числовые данные.
2. Выбрать тип графика по вопросу.
3. Нарисовать значения.
4. Добавить заголовок, подписи осей и единицы измерения.
5. Сделать подписи читаемыми и вызвать `plt.show()`.

`plt.show()` передаёт готовую фигуру графической среде. **Этот вызов сам по себе не гарантирует**, что рисунок появится в интерфейсе учебной платформы: перед публикацией преподаватель должен отдельно проверить, отображает ли песочница графический результат. Если платформа показывает только текст, выполнить код без ошибки недостаточно для выполнения визуальной части урока.

### 2.1. Столбчатая диаграмма: сравним три города

Ниже **фрагмент проверенной сводки RETAIL SALES**, а не исходные строки заказов. Показана учебная выручка завершённых позиций покупателей из трёх городов. Другие города здесь намеренно не включены, поэтому сумму этих трёх значений нельзя называть общей выручкой магазина.

| Город покупателя | Выручка, руб. |
|---|---:|
| Москва | 123 030 |
| Казань | 46 390 |
| Новосибирск | 4 200 |

**Задача:** сравнить города по выручке, не перепутав высоту столбца с числом заказов.

```python
import pandas as pd
import matplotlib.pyplot as plt
from io import StringIO

csv_text = """city,revenue
Москва,123030
Казань,46390
Новосибирск,4200
"""

df = pd.read_csv(StringIO(csv_text))

plt.figure(figsize=(8, 4))
plt.bar(df["city"], df["revenue"])
plt.title("Выручка покупателей из трёх городов")
plt.xlabel("Город покупателя")
plt.ylabel("Учебная выручка, руб.")
plt.ylim(bottom=0)
plt.grid(axis="y", alpha=0.3)
plt.tight_layout()
plt.show()
```

**Что должно появиться:** три вертикальных столбца, подписанные городами. Самый высокий — Москва, следующий — Казань, самый низкий — Новосибирск. На вертикальной оси указаны рубли; горизонтальная ось показывает **город покупателя**, а не место доставки.

Разбор новых команд:

- `plt.figure(figsize=(8, 4))` задаёт размеры рисунка (ширина и высота в дюймах).
- `plt.bar(x, y)` строит столбцы: по оси X — города, по Y — выручка.
- `plt.title()` задаёт заголовок; `xlabel()` и `ylabel()` подписывают оси.
- `plt.ylim(bottom=0)` сохраняет нулевую нижнюю границу: так визуальное сравнение длин столбцов не преувеличивается.
- `plt.grid(axis="y", alpha=0.3)` добавляет ненавязчивую сетку для оценки значений. Параметр `alpha` управляет её прозрачностью.
- `plt.tight_layout()` помогает не обрезать подписи.

Для длинных названий категорий можно использовать `plt.xticks(rotation=30, ha="right")` — поворот надписей по оси X, либо горизонтальные столбцы `plt.barh(...)`. Для горизонтального графика название категории обычно располагается по оси Y, выручка — по оси X. Длина столбца здесь важнее декоративной окраски.

### 2.2. Подписи и честный масштаб

Плохой вариант: вертикальная диаграмма с осью выручки, которая начинается не с нуля и из-за этого делает небольшое различие между категориями похожим на огромный разрыв. Если задача — **сравнивать величины по длинам столбцов**, нулевая база обычно необходима.

Другие проблемы: не подписаны рубли; длинные названия налезают друг на друга; заголовок не говорит, **что** и **за какой период** показано; в графике смешаны выручка и количество без объяснения.

**Небольшая проверка понимания:** если по оси X стоят категории, а по оси Y — выручка, означает ли самый высокий столбец наибольшее число проданных единиц? **Нет.** Цена товаров влияет на выручку; больше единиц не обязательно означает больше денег.

## 3. Линейный график: последовательность во времени

Столбцы сопоставляют отдельные категории. **Линия** помогает проследить, как показатель меняется от одного периода к следующему.

Для первого знакомства возьмём **условные тренировочные данные**, не являющиеся продажами RETAIL SALES: количество обращений в учебную службу поддержки за три недели.

```python
import pandas as pd
import matplotlib.pyplot as plt
from io import StringIO

csv_text = """week,requests
Неделя 1,5
Неделя 2,8
Неделя 3,6
"""

df = pd.read_csv(StringIO(csv_text))

plt.figure(figsize=(7, 4))
plt.plot(df["week"], df["requests"], marker="o")
plt.title("Обращения в учебную поддержку по неделям")
plt.xlabel("Период")
plt.ylabel("Количество обращений")
plt.grid(alpha=0.3)
plt.tight_layout()
plt.show()
```

**Ожидаемый вид:** три точки со значениями 5, 8 и 6, соединённые линией в порядке недель. `plt.plot()` строит линию, а `marker="o"` делает отдельные наблюдения видимыми.

**Как читать:** со второй недели относительно первой показатель вырос на 3 обращения, а на третьей уменьшился на 2 относительно второй. Мы видим динамику, **но не знаем причин**: рост мог быть связан с нагрузкой, изменением процедуры учёта или другими обстоятельствами.

Для даты или месяца последовательность особенно важна. Перед построением временного графика убедитесь, что строки расположены в хронологическом порядке; для строк вида `2025-01`, `2025-02`, `2025-03` обычная сортировка текста даёт правильный календарный порядок.

### 3.1. Работа с итогами pandas

В реальном небольшом анализе значения для графика часто получают из нескольких шагов:

`CSV → DataFrame → фильтрация → вычисление → groupby() → сортировка → matplotlib`.

Если у вас уже есть сгруппированный результат с названиями категорий и суммами, передавайте эти два столбца в `plt.bar()` или `plt.barh()`. Если данные являются датированными наблюдениями, передавайте периоды и значения в `plt.plot()`.

**Не заменяйте измерение интерпретацией.** График показывает числа из выбранных записей. Он не сообщает автоматически о прибыли, причинах изменения продаж или будущем поведении покупателей.

### 3.2. Как не скрыть важные ограничения

- Уточняйте, что график построен только по завершённым позициям: отменённые продажи не входят в учебную выручку.
- Не скрывайте бесплатную завершённую позицию: она даёт ноль рублей выручки, но существует в данных.
- Не смешивайте город покупателя с адресом доставки. В исходной сводке RETAIL SALES есть **460 рублей завершённой выручки покупателя с неизвестным городом**; такой вклад нельзя незаметно удалить, если вы показываете полную сводку по городам.
- По трём месяцам нельзя объявлять долгосрочную сезонность или причину падения и роста. Совместное изменение двух величин не доказывает причинную связь.

## 6. Итоги урока

Теперь вы умеете выбирать визуализацию по вопросу, строить столбчатые и линейные графики через `matplotlib`, переносить подготовленные pandas-итоги на оси, подписывать рубли и периоды, а также проверять, не вводит ли график читателя в заблуждение.

**Алгоритм аналитика:** задать вопрос → проверить данные → рассчитать показатель → выбрать тип графика → подписать оси → объяснить наблюдение → назвать ограничения.

В заключительном проекте вам понадобится пройти эту последовательность самостоятельно. Помните: **график показывает результаты анализа, но сам по себе не доказывает причины изменений**.
