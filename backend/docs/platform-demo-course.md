# Демонстрация платформы — курс 4

Курс сохраняет `course_id=4`, slug `platform-demo`. Каталог показывает его первым
благодаря `sort_order=0`, а не перенумерации существующих курсов и путей MinIO.
Обычный порядок остальных курсов остаётся 1, 2, 3. В поиске сохраняется ранжирование
по релевантности; среди записанных курсов приоритет учитывается перед датой записи.

Добавлена миграция `V12__course_catalog_order.sql`. До запуска обновлённого API
нужно применить её и `R__demo_course.sql`. Сброс БД не нужен.

## Контент

Нумерация внутри курса — модуль 1 и уроки 1–2. В таблицах используются глобально
уникальные технические ID: `module_id=11`, `lesson_id=24` и `25`. Они не меняют
видимые номера в заголовках и позициях. Исходные Markdown перемещены по путям,
которые действительно запрашивает backend:

- `course-content/4/11/24.md` — «Урок 1. Знакомство с проектом», 10 слайдов.
- `course-content/4/11/25.md` — «Урок 2. Видеодемонстрация платформы».

Все десять предоставленных WebP зарегистрированы с реальными размерами и
связаны с первым уроком. Их порядок определяется блоком `:::slides` в Markdown.
Обложка `4/main.webp` зарегистрирована отдельно в `course_images`.

Второй урок связан с видео `m_bb0da2e8512e430r` и ссылается на него обычной
разметкой `![описание](asset:m_bb0da2e8512e430r)`. Ожидаемый файл в MinIO:

```text
course-content/4/media/m_bb0da2e8512e430r.mp4
```

Видео пока отсутствует: размер 0 в сиде означает неизвестный размер, разрешение,
кодеки и длительность не выдумываются. До загрузки видео плеер не сможет его
воспроизвести. После загрузки нужно проверить MP4/H.264/AAC и актуализировать
метаданные; повторный запуск сида не затирает проверенные метаданные заглушкой.

Изменения файлов сидов сами не меняют работающую БД или объекты MinIO.
После миграции и заполнения загрузите контент и изображения в MinIO и
перезапустите API. `make storage-refresh` в текущем проекте пересоздаёт содержимое
баков из сидов — учитывайте это, если в MinIO есть файлы, отсутствующие в репозитории.

Проверки без Docker и внешней БД:

```bash
venv/bin/python -m pytest tests/test_demo_course.py -q
```
